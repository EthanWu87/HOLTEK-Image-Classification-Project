# HOLTEK TinyML Project

This repository contains a TinyML image classification project based on the **HOLTEK HT32F49395** microcontroller and **HIMAX HM01B0** grayscale image sensor.

The project provides a complete workflow for image data collection, model training with **Edge Impulse**, and on-device image classification.

## Project Overview

The system consists of two main parts:

* **Firmware** running on the HOLTEK HT32F49395.
* **PC Software** for image data collection and visualization of inference results.

The general TinyML workflow is:

```text
HM01B0 Camera
      ↓
HT32F49395 Image Capture
      ↓
PC Data Collection Software
      ↓
Dataset
      ↓
Edge Impulse
      ↓
MobileNetV1 Image Classification Model
      ↓
HT32F49395 On-device Inference
      ↓
Classification Results
```

---

## Hardware

* **MCU:** HOLTEK HT32F49395
* **Development Board:** ESK32-AE401 TinyML Board
* **Camera:** HIMAX HM01B0
* **Image Type:** Grayscale
* **Communication Interface:** UART

The HM01B0 camera is controlled by the HT32F49395 and image data is captured using hardware peripherals with DMA to reduce CPU intervention during image acquisition.

## Firmware

### 1. Data Collection

The `data_collection` firmware is used to capture images from the HM01B0 camera and transmit the image data to a PC.

Main functions:

* Initialize the HM01B0 image sensor.
* Configure the HT32F49395 image capture peripherals.
* Capture grayscale image data.
* Use DMA for image data transfer.
* Store the captured image in the MCU image buffer.
* Send image data to the PC through UART.
* Support dataset collection for TinyML model training.

The captured images can be received by the PC-side Data Collection software and saved as training samples.

---

### 2. Run Classification

The `run_classification` firmware performs image classification directly on the HT32F49395.

Main functions:

* Initialize the HM01B0 camera.
* Capture image data from the camera.
* Prepare the image for the neural network input.
* Run the Edge Impulse inference engine.
* Execute the MobileNetV1 image classification model on the MCU.
* Output classification labels and confidence scores.
* Report inference timing information through UART.

Example output:

```text
Predictions:
DSP: 46 ms
Classification: 182 ms
Anomaly: 0 ms

paper:    0.00000
scissors: 0.00000
stone:    0.80859
unknown:  0.18749
```

## Software
### 1. Data Collection

The Data Collection software is used to receive images captured by the HT32F49395 through UART.

Main functions:

* Connect to the HT32F49395 through a serial port.
* Receive grayscale image data from the MCU.
* Convert the received image buffer into an image.
* Display the captured image in real time.
* Save captured images to the PC.
* Assist in creating datasets for Edge Impulse training.

---

### 2. Run Classification

The Run Classification software is used to receive and display the inference results generated by the HT32F49395.

Main functions:

* Connect to the development board through UART.
* Receive inference results from the MCU.
* Parse classification labels and confidence scores.
* Display the predicted class.
* Display DSP, classification, and anomaly processing times.
* Monitor the TinyML model during real-time operation.

## Development Workflow

### Step 1 - Collect Images

Flash the `data_collection` firmware to the HT32F49395.

Run the Data Collection software on the PC and capture images for each classification class.

```text
Camera → MCU → UART → PC → Dataset
```

### Step 2 - Train the Model

Upload the collected dataset to Edge Impulse.

Typical processing flow:

```text
Image Dataset
      ↓
Resize / Preprocessing
      ↓
96 × 96 Grayscale Input
      ↓
MobileNetV1
      ↓
Transfer Learning
      ↓
Image Classification Model
```

### Step 3 - Deploy the Model

Export the trained model using the Edge Impulse C/C++ SDK and integrate it into the HT32F49395 firmware.

### Step 4 - Run Classification

Flash the `run_classification` firmware.

The HT32F49395 will continuously:

```text
Capture Image
     ↓
Image Preprocessing
     ↓
MobileNetV1 Inference
     ↓
Classification
     ↓
UART Output
```

The PC-side Run Classification software can be used to monitor the inference results.
